### Welcome to Version -0.0.0 of ExtreCalc!

This is a Python Big Number calculator I've been working on for quite a while. Made by 1-Ball (Robert Kim) with the help of many others.
The current version is **not** complete. **That's** why the version number is -0 instead of 0. :)

### What exists:
- BigInt
- BigDecimal
- SciNot (Scientific Notation)
- ExpantaNum
- many operations

### Issues:
- When you use a function for a thing that said function doesn't support, it sometimes will just break the entire thing instead of returning an error.
- There are **several** problems with the classes.
- Some precision tests fail.

### Coming Soon:
- Exact for rationals and radicals
- Advanced Functions
- Infinite Ordinal support
- Fast-Growing Hierarchy
- Precision Fixes
- Bug Fixes
- Classes working normally
- Better UI: right now you have to run it in the Terminal

### Below is a list of all functions and operations:
 a + b --------------------- addition\
 a - b ------------------ subtraction\
 a * b --------------- multiplication\
 a / b --------------------- division\
 a ^ b --------------- exponentiation\
 a // b ------------ integer division\
 a % b -------------------- remainder\
 sqrt(a) ---------------- square root\
 log10(a) --------- base-10 logarithm\
 logb(a,b) --------- base-b logarithm\
 a! -------------- factorial function\
 a{c}b -------------- hyperoperations\
 ackermann(a) -- ath ackermann number\
 ackermann(a,b) -------------- A(a,b)\
 sciNot --------------- format to xEy\
 hyperE -------------- format to Ex#y\
 superBool --- Toggle Fancy Exponents\
 separator ------ Toggle ' Separators
